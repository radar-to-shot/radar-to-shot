Golden outputs are observations from the original Robot Warriors 1.0.1 machine
code running under a Motorola 68000 emulator. Their expected values must never
be generated by the native C++ implementation.

`validate_golden.py --binary build/robotwar` reads the committed vector files,
sends inputs to the native JSONL interface and compares complete output objects.
It fails when there are no cases, when a process fails, when response counts differ,
or when any result differs. It does not rewrite fixtures.

Original-code regeneration requires the Python packages in
`tools/requirements-reverse.txt`. The emulator records source CODE hashes,
instruction counts, and any Macintosh trap dependencies with its outputs.
